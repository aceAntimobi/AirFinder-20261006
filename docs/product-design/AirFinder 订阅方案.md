# Air Finder 完整订阅方案

版本：1.0 · 2026-10-06
适用范围：当前 W01–W19 原型、iOS 与 Android 订阅链路。

## 1. 方案结论

产品保留 3 个商品、4 类订阅场景，不增加新套餐：

1. 首启 W05：只销售无试用周套餐，允许关闭后继续免费使用。
2. 寻找中 W09：默认年套餐，可切换无试用周套餐；成功后续接同一台设备的寻找。
3. 常规会员 W19：默认年套餐，可切换无试用周套餐；成功后进入 W18。
4. W11/W12/W13/W16/W17 试用卡：销售带首购试用的周套餐；成功后留在发起页。

统一会员权益：

- 查找目标设备的信号引导；
- 不限次数使用蓝牙设备检测；
- 完整使用寻找过程中的信号趋势和移动建议；
- 移除广告。

## 2. 商品目录

| productId | 类型 | 当前原型价格 | 试用 | 使用场景 | 默认选择 |
|---|---|---:|---|---|---|
| `airfinder_7d_default` | 自动续订周套餐 | `$6.99/week` | 无 | W05、W09、W19 | W05 默认；W09/W19 非默认 |
| `airfinder_12m_default` | 自动续订年套餐 | `$39.99/year` | 无 | W09、W19、W18 周转年 | 默认 |
| `airfinder_7d_3dtrial` | 自动续订周套餐 | 试用后 `$6.99/week` | 当前说明为 3 天 | W11/W12/W13/W16/W17 试用卡 | 单商品 |

### 2.1 价格与试用的唯一口径

- 原型中的美元价格是当前设计基线，正式页面必须优先显示商店实时返回的本地化价格、币种和周期，不能用硬编码价格替代已获取的商店数据；当无法获得实时本地化价格时，显示原型中的默认美元价格。
- 只有商店返回“当前账号具备首购优惠资格”时，才展示 `Start your 3-day free trial`。没有资格时不展示免费试用承诺，改为普通周订阅价格与购买按钮。
- `$39.99/year` 折合约 `$0.77/week` 可以作为辅助信息，但同样要用本地化年价动态换算。

### 2.2 套餐选择规则

- 点击套餐卡只更新选中状态，不立即拉起商店购买。
- 只有点击主按钮后，才购买当前选中的商品。
- W09/W19 每次新进入默认选年套餐；同一页面停留期间保留用户刚才的选择。
- 商品不可用时禁用对应套餐卡；所有商品均不可用时，主按钮显示 `Subscriptions unavailable`，提供重试与恢复入口。

## 3. 权益定义

统一权益字段：`premiumEntitled`。只有商店验证后的有效权益才能置为 `true`。

| 商店/本地状态 | premiumEntitled | 页面处理 | 广告处理 |
|---|---:|---|---|
| 试用有效 | true | W18 显示 Trial Active 和到期/续费日期 | 不请求、不展示 |
| 周套餐有效 | true | 显示当前套餐和下次续费/到期日期 | 不请求、不展示 |
| 年度有效 | true | 显示当前套餐和下次续费/到期日期 | 不请求、不展示 |
| 已取消续订但尚未到期 | true | 显示有效至日期和 Auto-renew Off | 不请求、不展示 |
| 宽限期且商店仍授予权益 | true | 显示支付问题提醒，不中断功能 | 不请求、不展示 |
| 购买 Pending | false | 显示等待商店确认，禁止重复购买 | 暂停请求与展示 |
| 权益校验中/未知 | 不判定 | 显示检查中，不误显示免费或会员 | 暂停请求与展示 |
| 暂停、保留、到期、退款或撤销且商店已收回权益 | false | 进入免费状态；会员入口指向 W19 | 可按广告方案恢复 |

规则：

- “取消续订”只停止下一周期扣费，不立即收回已付费周期内的权益。
- 从后台、商店管理页、购买弹层返回时都刷新权益；刷新前不以缓存状态永久判定。
- 本地缓存只用于首屏过渡。缓存过期、账号变化或商店返回冲突时进入“校验中”，不得展示错误付费墙或广告。
- 同一订阅组只保留一个有效会员权益；商品变更不叠加多个会员身份。

## 5. 入口与页面规则

|---|---|---|---|---|

| 会员入口 → W19 | 免费用户主动点击会员入口 | 年套餐默认；周套餐可选 | 返回来源页 | W18 |

| W18 Upgrade | 当前有效周套餐用户 | 年套餐 | 取消后留在 W18 | W18，刷新年套餐状态 |

### 5.1 W05 首启订阅页

- 首启选择类型后进入，标题与第一条权益跟随 W03 类型。
- 只提供无试用周套餐，不暗示包含免费试用。
- 关闭和购买成功均进入 W06；关闭不会再次自动弹出 W05。
- 已有有效权益的用户恢复安装后，读取到权益即可跳过购买展示并继续 W06。
- W05 不在设置权限、普通回前台或二次扫描时复用。

### 5.2 W09 寻找中订阅页

- W08 的免费预览计时只在页面前台、目标有效且权益明确为免费时运行。
- 每个 `findingSessionId` 最多自动进入一次 W09；关闭后回 W07，不在同一会话循环弹出。
- 进入 W09 时锁定 `targetDeviceId`、展示名、类型和来源会话。
- 成功或恢复后返回 W08 前，重新检查权限、目标身份和最新广播；不得因重新扫描而换成同型号的另一台设备。
- 目标暂时失联时仍恢复 W08 的同一目标，显示 Reacquiring；目标记录已删除或会话失效时进入 W07 并明确提示。

### 5.3 W19 标准订阅页

- 由 W11/W12/W13/W16/W17 的会员入口在免费状态下打开。
- 默认选年套餐；周套餐不写 `Best for Short Trial`，避免用户误以为无试用商品包含免费试用。
- 关闭返回真实来源页。只有未发起购买/恢复、没有待续任务的普通关闭，才可按广告方案判断 BF42。
- 购买、恢复、取消或失败后的关闭均不触发 BF42。

### 5.4 试用卡

- 试用卡位于 W11/W12/W13/W16/W17，仅在权益明确为免费时展示。
- 试用资格确认前使用骨架/普通会员入口，不先显示“免费 3 天”。
- 有资格：点击后购买 `airfinder_7d_3dtrial`。
- 无资格：卡片改为普通周订阅文案，点击购买 `airfinder_7d_default`；不得继续展示 `free trial`。
- 成功后原地关闭卡片并刷新页面，不跳 W08。
- 同一次点击只允许发起一个交易；处理中禁用重复点击。

### 5.5 W18 My Premium

W18 至少支持以下状态：

| 状态 | 必备信息 | 操作 |
|---|---|---|
| Weekly Active | 周套餐、续费/到期日期、Auto-renew 状态 | Upgrade to Annual、Manage Subscription |
| Annual Active | 年套餐、续费/到期日期、Auto-renew 状态 | Manage Subscription |
| Cancelled but Active | 当前套餐、有效至日期、Auto-renew Off | Manage Subscription |
| Grace Period | 权益仍有效、支付问题提示 | Manage Subscription |
| Checking | 正在检查会员状态 | Retry |

- 只有有效周套餐显示年套餐升级入口；年套餐、试用状态不显示重复升级。
- 升级取消或失败时保留原周权益，停留 W18。
- 升级成功后仍停留 W18，刷新为年套餐及商店确认的生效日期。
- 点击 Manage Subscription 打开对应平台的订阅管理页；回到 App 后自动刷新权益。
- 权益确认已过期时，不展示 Premium Active，返回上一页后会员入口指向 W19；可在 W18 用失效态说明并提供 View Plans。

## 6. 统一购买状态机

所有 W05/W09/W19/试用卡/W18 共用原型中的交易状态，但成功后的业务路由由来源决定。

```text
默认订阅页
  ├─ 点击 Continue
  │    → 订阅处理中
  │         ├─ 订阅成功 → 按来源进入下一页
  │         └─ 首次订阅失败 → 自动重试拉起一次商店订阅
  │                   ├─ 重试成功 → 按来源进入下一页
  │                   └─ 重试失败 → 展示订阅失败，停留当前页
  └─ 点击 Restore
       → 订阅恢复中
            ├─ 订阅恢复成功 → 按来源进入下一页
            └─ 订阅恢复失败 → 展示恢复失败，并自动发起一次订阅
                         ├─ 订阅成功 → 按来源进入下一页
                         └─ 订阅失败 → 展示订阅失败，停留当前页
```

### 6.1 状态处理

| 状态 | 页面反馈 | 主按钮/下一步 |
|---|---|---|
| 默认订阅页 | 展示权益、套餐、Continue、Restore、条款与关闭按钮 | 可选择套餐并购买或恢复 |
| 订阅处理中 | 对应原型的订阅处理中提示 | 禁止重复点击和切换套餐 |
| 订阅成功 | 对应原型的订阅成功提示 | 1 秒后按来源续接 |
| 订阅失败 | 首次失败时自动重试一次；第二次失败显示对应原型提示 | 1 秒后关闭提示，停留当前页 |
| 订阅恢复中 | 对应原型的订阅恢复中提示 | 禁止重复恢复 |
| 订阅恢复成功 | 对应原型的订阅恢复成功提示 | 1 秒后按来源续接 |
| 订阅恢复失败 | 对应原型的订阅恢复失败提示 | 提示后自动发起一次订阅；订阅仍失败则停留当前页 |

### 6.2 交互规则

- 点击 Continue 后进入“订阅处理中”；商店返回成功或失败后切换到对应原型状态。
- 点击 Restore 后进入“订阅恢复中”；商店返回成功或失败后切换到对应原型状态。
- 首次订阅失败后自动重新拉起一次商店订阅，最多自动重试 1 次；第二次仍失败则展示“订阅失败”，1 秒后关闭提示并停留当前页。
- 订阅恢复失败后展示“订阅恢复失败”，随后自动发起一次订阅；订阅成功则按来源续接，订阅失败则展示“订阅失败”，1 秒后关闭提示并停留当前页。
- 成功状态停留 1 秒后，按照 W05、W09、W19、试用卡或 W18 的来源规则续接。
- 状态提示展示期间禁止重复点击，避免同一操作被重复提交。

## 7. 恢复购买

- W05、W09、W19 提供可见的 Restore。
- 恢复只恢复同一商店账号下、当前仍有效的会员权益，不恢复已经失效的免费试用资格。
- 恢复成功后使用当前页面的来源续接：W05 → W06；W09 → 同目标 W08；W19 → W18。
- 未恢复到有效订阅或恢复发生错误时，进入原型的“订阅恢复失败”状态，随后按原型自动发起一次订阅。
- 恢复过程中离页，结果仍可更新全局权益，但不强制覆盖用户当前正在进行的业务。
